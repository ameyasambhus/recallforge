# RecallForge Frontend

React + Vite client for RecallForge. This app powers the card workflow, review flow, folders, lists, and media previews.

## Highlights
- React 19 + Vite
- Tailwind + DaisyUI
- React Router, Axios, and Markdown rendering

## Development
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```
